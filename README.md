# VII The Game

Página de fan, hecha desde cero, de un **GTA VII** ficticio.

**Proyecto de fan no oficial. No afiliado con Rockstar Games ni Take-Two Interactive.**

Grand Theft Auto, GTA y las marcas relacionadas son propiedad de sus respectivos dueños. Este sitio es un homenaje independiente, sin fines de lucro y sin material tomado de rockstargames.com.

## Contenido

- Introducción con una estrella original (no es el logo de Rockstar)
- Portada a pantalla completa con un wordmark VII propio en SVG
- Tráiler de marcador de posición
- Personajes y lugares, recortados de la imagen de portada
- Bloque de «Próximamente» y un aviso por correo que solo se guarda en el navegador

## Local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 4173
```

Añade `?intro=0` para saltar la introducción, o `?intro=hold` para dejarla fija.
